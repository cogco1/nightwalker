《夜行者》v10 · 游戏内改键

F1 / Esc 或顶部「改键」打开暂停设置。点击项目按钮，按下单键或鼠标键，再点「保存并返回」。
「取消」丢弃草稿；录入时 Esc 先取消录入，再按 Esc 返回；「恢复默认」保存后才生效。

可编辑 12 项：四向移动、按住跑步、跳跃 / 二段跳、下蹲 / 下劈、上挑修饰键、突刺修饰键、攻击鼠标键、切换视角、重置。
普通攻击只绑定鼠标；J 和键盘攻击项已移除。
地面和空中的突刺均为 Shift + A / D + 新一次左键点击，三个键随各自改键设置变化。
轻击是点击攻击鼠标键；重斩是按住同一个键蓄满后松开，不需要单独改键。
双跳沿用跳跃键，下劈沿用下蹲键；上挑沿用上挑修饰键和攻击鼠标键。
Esc / F1 保留为设置入口。上下移与对应侧视动作允许共享；跑步和突刺修饰键也允许共享。
保存到 user://keybindings.cfg，重启自动读取。v01/v02 配置保留已有绑定，补充 Shift 突刺修饰键，忽略旧 J 攻击项。
支持键盘单键及鼠标左 / 右 / 中 / 侧键。冲突会显示说明；保存失败保留原绑定，不完整配置回退默认。

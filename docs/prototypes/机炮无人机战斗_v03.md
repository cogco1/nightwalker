# 烛眼：机炮无人机战斗 v03

接在狙击手开发版本496c188上，提供独立战斗试玩。运行Run-Drone.cmd，或Godot 4.7.2运行game/scenes/drone_combat_test.tscn。
第一章入口、原无人机美术预览和狙击手战斗试玩保留。本轮只复用选定无人机B的悬浮帧，不播放旧激光束动作。

## 操作

移动、跳跃、轻重攻击、蓄力、闪避和完美闪避保护沿用正式主角。
1远距、2近距、3换到无人机另一侧，B将其置于濒死状态，C开关实体掩体，R重新挑战；F1改键，Esc退出。
玩家死亡后重新开始，无人机被摧毁后按R重来。

## 悬浮与机炮

身体、碰撞体、伤害点和枪口共用一个真实移动根节点。固定原生像素比例，角色scale=1，最近邻过滤。
缓慢水平巡浮叠加低幅上下呼吸；实际位置由解析临界阻尼弹簧跟随目标，不以正弦偏移瞬移贴图。
机炮瞄准时平滑减速稳住，仅保留轻微呼吸；每发加入很小的物理后坐，随后由同一悬浮控制吸收并恢复。
墙体通过CharacterBody2D实际阻挡，暂停和完美闪避慢动作统一影响悬浮、动作、射击与弹丸。
巡浮基准为出生区域，默认半径64像素，不作跨地图追击。受近身压力小幅拉开位置；命中和蓄力攻击会推动真实机体，之后平滑回稳。

攻击先追踪瞄准0.85秒，最后0.20秒锁定，再发射三发机炮弹，间隔0.22秒。
同一轮保持锁定方向；玩家穿过背后不会使正在射击的机体瞬间反转追踪。点射完成后再换侧瞄准。
点射结束后0.45秒收势，冷却1.55秒包含该收势时间。视距390像素，失去视线或受到攻击取消未完成点射。

机炮沿用共用大口径弹丸：速度230像素/秒、射程460、伤害20、击退参数22、曳光长30像素。
亮色弹芯、橙色曳光、光晕和枪口闪光均为实际弹道绘制。每弹只结算一次，扫掠检测先遇到的墙或玩家，保留真实闪避。
此前“狙击弹/机炮弹击退，步枪/霰弹枪弹不击退”的规则保持。

## 濒死自爆

- 默认生命12；降到3或以下且仍存活时启动自爆，不再射击。
- 1.20秒闪红警报，红圈标明64像素爆炸半径。悬浮逐渐稳住，警报随倒计时加速。
- 倒计时结束一次爆炸，伤害35、击退参数34；机体消失，显示短促亮芯、暖色冲击环和碎屑。
- 伤害按玩家真实受伤区域到爆心的最近距离结算；实体墙阻挡爆炸。远离范围或及时闪避可以无伤。
- 警报期间仍可补刀。生命清零会取消自爆；直接一击击杀从正常生命落到0也不触发濒死阶段。
- 普通受击反应不清空已开始的自爆倒计时；剧情暂停和菜单暂停会暂停倒计时，避免恢复操作即遭爆炸。
- 爆炸只结算一次。机体已销毁时没有可传送反击的目标，原有闪避与完美闪避保护仍生效。

game/scripts/enemies/cannon_drone.gd为可复用敌人；game/scripts/drone_combat_test.gd和对应场景为试玩。

本轮7组650项通过，失败0：无人机30/60/144Hz各56项；狙击手60Hz 135项、原敌人29项、完美反击31项、原动作预览287项。

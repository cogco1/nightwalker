# 打击感原型：剑气破屏和轻微震屏（2026-10-18）

用户 10-18 直接提出：“做一个原型设计，让打击更具效果，剑气看起来像冲出屏幕，然后加轻微的屏幕震动”，并说“按你的理解先做个原型，用 GitHub 最新版的”。下面的取舍都是开发会话自己定的，等用户试玩后再定留不留、怎么调。

基线是 main `a5c0987`（v2026.10.18 战斗基线 + 第一章 M2）。原型叠在已有的“打击感 v2”上（`impact_v2.gd` 的墨色刀痕和飞溅、GameSession 的顿帧和镜头回弹），沿用它的美术方向：墨黑 + 暗红，不用加法发光，不做全屏闪白。

## 怎么试

- 默认开着。**F10** 随时开 / 关，屏幕上方提示“打击原型 开 · F10”/“关”，方便和原版对比（如果玩家把某个动作改绑到 F10，F10 让给那个动作）。
- 最直接：`powershell -File tools\Run-Game.ps1 -Step d1_night`，第一夜的安保面前：
  - 按住左键约 0.6 秒松开（蓄力拔刀斩）；
  - 右键（重劈）；
  - 左键连点三下（第三刀暴击时）。
- 夜街（`Run-NightStreet.cmd`）打无人机也一样生效。
- 对比视频：`tests/recorders/record_impact_burst.gd` 录第一夜，`tools/art_qa/compose_impact_burst.py` 合成左右对比（左开右关），正常速度和半速各一段。

## 做了什么

| 部分 | 什么时候 | 样子 |
|---|---|---|
| 剑气飞斩 | 重招挥出时：蓄力拔刀斩、右键重劈、追影重斩、回旋重斩收尾、完美闪避反击、空中旋转斩收尾（`QI_MOVES`）；只在侧视 | 刀尖前放出一道月牙剑气：墨黑描边、暗红主体、余烬红边、中段一道细亮芯，后面拖三道残影和几条速度线。飞行 0.36 秒，越飞越快、越飞越大（从半高 25 像素长到比屏幕还高），像是朝镜头冲出来；盖在界面上面，飞出屏幕边时边缘裂开一道锯齿裂口、溅出墨红碎片 |
| 破屏斩线 | 暴击、重击、击杀命中（顿帧那一下） | 从顿帧第 2 帧起，一道斜线穿过命中点贯穿整个屏幕、两头都伸出画面，线两侧的画面沿线错开 2 像素（像屏幕被一刀切开，界面字也会被切到）；顿帧一结束画面合上，斩线 0.16 秒内淡掉 |
| 轻微震屏 | 每次顿帧结束后 | 原来只是沿攻击方向回弹一下；现在是来回抖几帧：轻击 3 帧 ±1 像素，暴击、重击、击杀 5 帧，横向最多 3 像素、纵向 1 像素，最后回到原位（不超过打击感 v2 定的 3 像素上限） |

- 剑气只是画面，不打人，也不改伤害和判定。
- 顿帧会拍一张“定格画面”；原型的图层在拍照那一帧先藏起来，免得飞着的剑气在定格画面里留下一个不动的副本。
- 原型的图层不跟着顿帧整体平移（加了 `no_stop_shift` 组）。

## 代码

- `game/scripts/core/impact_burst.gd`：原型本体，GameSession 的子节点（所有有玩家的场景都有，测试夹具也有）。参数都在文件开头：`QI_MOVES`（哪些招放剑气、多大）、`QI_LIFE / QI_TRAVEL / QI_RADIUS / QI_GROWTH`（飞多久、多远、多大）、`CUT_WEIGHTS / CUT_FADE / SPLIT_PX`（哪些档位切屏、切多久、错开多少）、`TREMORS`（每档震屏的逐帧位移）。
- `game/shaders/screen_cut.gdshader`：沿斩线把两侧画面反向错开，按整原生像素移动，窗口分辨率的界面字仍然清楚。
- `player.gd` 加了 `struck(点, 档位, 方向, 是否击杀)` 信号（命中点）；`game_session.gd` 加了 `stop_weight()`，顿帧后的镜头位移改成问原型要（关掉时还是原来的回弹）。

## 验证

- `tests/test_impact_burst.gd`（60 Hz 和 144 Hz 各 39 项）：默认开、真实 F10 开关和提示、F10 被改绑时让出；蓄力松开放出一道剑气，往前飞、越飞越快越大、飞出屏幕边会撕裂，顿帧期间照样飞，轻击和俯视不放，数量有上限；重击命中从顿帧第 2 帧起切屏、两头伸出屏幕、顿帧结束合上、随后淡掉，轻击不切、暴击切，关掉后什么都不出；顿帧拍照那一帧原型图层藏起来，图层不跟着顿帧平移；震屏横竖都抖、不超过 3/1 像素、回到原位，关掉后恢复原来的回弹。
- 原有 `combat_impact_v2`（60/144 Hz）的镜头上限和复位检查照样通过。

## 等用户定

2026-10-18 用户看过对比视频后说“效果可以，先这样，等总协调那边走合并”，PR #7 已合并（`ceb00ff`）。下面几项用户没另外提，先保持现状（默认开、F10 开关；剑气不伤人；切屏会切到界面字；震屏照现在的幅度），细节待定：

- 留不留、默认开不开，F10 开关正式版要不要保留。
- 剑气是否要真的能打人（远程判定会改平衡），以及哪些招式放。
- 破屏斩线会短暂切过界面字；是否接受，还是只切游戏画面。
- 震屏幅度：现在守着原来的 3 像素上限，想要更明显可以放宽。

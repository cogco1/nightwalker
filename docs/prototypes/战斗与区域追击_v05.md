# 战斗反馈与区域追击 v05

运行 `Run-Drone.cmd`，体验本轮全部改动。包含此前狙击手、机炮、低血自爆及0.65秒受击保护；本轮为本地交付，尚未同步GitHub。

## 大幅度受击与轻微镜头抖动

正面受击的头肩位移由6增至11原生像素，背面由7增至13；正面上提2像素、背面下沉4像素。冲击到峰值后略作停留，再在0.3秒硬直内回正。左右朝向均支持，仍采用现有像素造型的程序化腰部弯曲动画。

玩家真正受伤时，镜头沿来袭方向作约0.1秒的轻微抖动，单轴最多1原生像素，最大合位移约1.42像素，结束后精确恢复原偏移。闪避、完美闪避、受击保护挡下的攻击不触发受伤镜头抖动。镜头暂停、切换和命中停顿使用同一恢复机制，避免残留偏移。

## 完美闪避与反击

短按并松开Shift进行普通闪避。敌人攻击到达前0.2秒内或有效命中窗口内完成闪避，会触发完美闪避：

- 切换为专用的0.24秒、6姿势闪避动画。侧视表现为压低身体、滑步跨出和恢复站姿，配合青色残影与瞬间闪光；普通翻滚使用原动作。该短片由既有角色姿势重新编排，未新画人物帧。
- 世界以25%速度运行1.2秒，玩家保持原速度并受到闪避保护，界面提示可以反击。
- 在窗口内点击左键或右键，消耗一次机会施放三倍伤害反击；命中后结束慢动作。可以提前接反击取消专用闪避动作。
- 附近260像素内的存活目标，身体路径和落点均畅通时，可闪到目标背侧反击。实体墙阻挡、目标过远、已死亡或来源不存在时，施放原地强化反击，避免穿墙和追向无效目标。
- 窗口用尽后恢复普通攻击；菜单暂停动作和窗口计时。专用动画不增加普通闪避的距离和时间。

## 无人机的大范围追击

出生点是固定区域中心，默认半径280像素，并为整个碰撞体预留14像素边距。无人机只对区域内玩家建立常规追击；以平滑移动的悬浮站位追近玩家，瞄准和点射期间稳住机体。普通追击速度约48像素/秒，接近后保持射击距离。

没有在区域内接敌的玩家不会引起全图追逐。区域中心不随无人机运动移动；常规移动、受击位移和特殊冲撞都经过区域边界约束，并保留真实墙体碰撞。

共用组件为 `game/scripts/enemies/enemy_territory.gd`。它只提供出生区域、目标判断、受限目标/位移和返回出生点；新怪物接入规则写在同目录 `AGENTS.md`。无人机专属自爆不进入共用组件。已约定驻守的小范围狙击手保留其独立配置。

## 撤远冲撞自爆：无人机专属

无人机曾与区域内玩家接近到170像素以内后，若玩家持续0.65秒撤至230像素以外，或离开出生区域，会停止机炮并进入0.5秒红色冲撞预警。

预警结束锁定一次冲撞方向，速度从36以300像素/秒²增加，最高220像素/秒；遇到玩家、实体障碍、区域边界或持续1.6秒就引爆。冲撞不跟踪转弯，不会穿墙或越过区域继续追逐。爆炸仍为64像素范围、35伤害及击退，因而刚越过区域边缘但仍贴近爆炸的玩家仍需继续撤离。

低血量自爆独立保留：生命12降至3或以下，自动停火并以1.2秒闪红预警自爆。两种自爆都可以补刀击杀中止，爆炸伤害仍支持掩体、闪避和受击保护。其他怪物只复用区域追击，不默认拥有这两种自爆。

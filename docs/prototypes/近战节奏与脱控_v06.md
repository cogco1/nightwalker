# 近战节奏与脱控 v06

运行 `Run-Melee.cmd` 进入独立近战试玩。1为狙击手枪托、2为安保警棍、3为多人围攻，R重开，F1改键。AD移动，短按并松开Shift闪避，完美闪避成功后点击攻击反击。此前无人机和狙击手试玩仍包含在完整工程中。

## 前摇、命中与收招

现有安保警棍、共用突袭近战和狙击手枪托采用统一节奏：

| 阶段 | 默认时长 | 表现与规则 |
| --- | --- | --- |
| 前摇 | 至少0.55秒 | 闪红、抬武器；先跟踪再锁定方向，尚不造成伤害 |
| 命中 | 约0.10秒 | 只结算一次，不在有效窗口中重复扣血 |
| 收招 | 至少0.55秒 | 武器收回、保持空隙，不能继续造成近战伤害 |
| 再次攻击间隔 | 至少0.80秒 | 完成当前动作后再开始下一轮，原兵种较长间隔继续有效 |

共用策略为 `game/scripts/enemies/melee_rhythm.gd`。玩家仍在受击硬直，或近战保护剩余时间较长时，敌人不立即开始新一轮近战。安保的收招使用独立放低警棍姿势；狙击手原有8姿势按前摇、出手、收招重新分配，视觉与命中时刻同步。

安保突进通过真实身体移动和墙体碰撞，近战结算检查视线，不能隔墙打中玩家。已开始的近战保持承诺方向，玩家可以绕开或越过敌人。

## 防止连续近战硬控

玩家真正被近战命中后，受击硬直仍约0.3秒，同时开启0.9秒共用近战保护。保护对不同近战来源共用；其他近战不能再次扣血、叠加击退、重置硬直或刷新保护期限。因此硬直结束后仍有约0.6秒操作余量。保护结束后可以正常再次受伤。

原有0.65秒通用受击保护继续处理弹丸等攻击。后续近战需标记 `attack_kind: melee`，也识别既有 `rifle_butt` 等近战武器。新敌人的近战约定已存入 `game/scripts/enemies/AGENTS.md`。

## 硬直中提前闪避

玩家在受击硬直内短按Shift，输入会保留到硬直结束后的短暂余量，恢复操作时立即执行闪避。它不会提前取消受击动作。被保护挡住的攻击不清除这次输入。

近战保护期间，玩家主动打出的新闪避仍按时机判断完美闪避，避免保护吞掉成功反馈。被动挨到攻击只会躲过伤害，不会自动获得完美闪避；专用闪避动画与三倍反击继续有效。

新套件验证了前后摇、真实普通闪避/完美闪避、硬直末端缓冲闪避、收招中反击、多人围攻的受击间隔、0.65秒通用保护结束后的额外近战保护、到期后正常受伤，以及墙体、慢动作和菜单暂停。多人围攻实测最长连续硬直约0.31至0.33秒，期间反复获得可操作窗口。

# 夜街赛博原型：改动清单

分支 `proto/night-street-cyber`，基于 main（v14，结构整理后）。2026-10-15；同日补正式底图 v15 和义体细节。

## 拍板口径（用户 10-15）

- 放开发光和义体：刀刃发光、目镜、反光条、发光条码都可以。
- 配色：佩特拉玫瑰砂岩加霓虹（监控青、黑市洋红、钠灯橙）。
- 主题：光 = 被监控。
- 兜帽保留。原型阶段不重画任何人物帧。
- 夜街做成单独的侧视场景，不接进正式流程；人物 shader 在所有场景生效。

## 任务对照

| 任务书 | 做法 | 和任务书的差别 |
|---|---|---|
| 1. 调色板替换 shader | `shaders/character_cyber.gdshader` + 18 × 3 查找表 `assets/fx/cyber_palette.png`，一个材质覆盖全部 1024 帧 | 任务书按 v07 写的 17 色；v14 多了空中突刺帧的 #566170，所以是 18 色 |
| 2. 轮廓光 | 同一个 shader：两个光源方向，只给朝光且外侧透明的边缘上色，背光一侧压暗。夜街每帧取最近最强的两盏灯（小吃亭洋红、光束青色、街灯钠橙） | 安全屋、医院没有灯光表，用默认的弱顶光 |
| 3. 刀刃发光 | 按颜色识别：刀刃三种钢色是自发光像素，帧内画 3 像素光晕 | 没用 `weapon_masks`：遮罩只覆盖 24 个侧视动作（共 64 个）。实测 v07 侧视帧里这三种钢色 99.6% 落在遮罩内，按颜色识别覆盖全部动作 |
| 义体（新增） | 目镜：脸部两种肤色映射成发光洋红。反光条：斜挎带、腰带、肩带（#533729）在暗处是暗银色，被灯照到亮成那盏灯的颜色，站进光束全亮。条码疤：握刀手前臂上一块被刮掉的条码，偶尔闪红；光束扫到时故障闪烁，头顶弹出扫描面板“ID 无法识别” | 都没动帧：反光条走查找表第 4 行；条码疤是叠加节点，逐帧锚点由脚本从帧里算出（800 帧 / 50 个动作，刀太短的 14 个俯视动作不显示）。按设定（SK.txt）主角没有身份序列号，所以不做完整发光条码，完整条码放在街上的身份闸门和 C 区广告牌上 |
| 4. 侧视场景 | `scenes/night_street_proto.tscn`：CanvasModulate 压暗，14 盏 PointLight2D（位置从底图算出），巡逻无人机光束（含 110 颗微光粒子），A 区巨塔和总控塔 / 佩特拉卡兹尼神殿式立面 / C 区楼房和金域大厦三层视差加街面层，湿地反光，雨，低雾。底图 v15 由本机 Codex image_gen 生成后降到原生像素 | 多了一个街面层（视差 1.0）；Codex 最宽只出 3:1，佩特拉视差改为 0.34，C 区按楼拆开重排到 768，街面接镜像到 960 |
| 5. 辉光 | 先测了：WorldEnvironment 辉光在 4.7.2 Compatibility 的 2D 下可用，超过 1.0 的颜色晕得更开 → 直接用，阈值 1.0，只有自发光像素会晕 | 不需要写假辉光 shader；人物 shader 自带的帧内光晕保证没有辉光的场景里刀刃也发光 |
| 6. 暴露度 HUD | 右上暴露条；进光束上升（约 1.8 秒满），出光束回落；画面按暴露度加 1 像素色差和边缘色 | 新增“已被标记”：暴露满后光束变红并追人，色差闪动，回落到 0.35 以下解除 |

## 和交接约束的出入

- 交接说明要求保留“原始人物配色、长刀白蓝刀光”。这个分支按用户 10-15 的决定改成赛博配色；原帧没动，回退只要把 `player.tscn` 里那一行 material 删掉，或把材质的 `look` 设成 0。
- 旧的 v07 美术校验脚本（`tools/art_qa/validate_sword_art_v07.py` 等）拿实机截图比对原配色，在这个分支上重录后会报配色不同，属于预期。

## 已知问题和下一步

- 底图 v15 是生图降采样，不是逐像素手绘：塔楼墙面有些杂点，C 区后半段是前半段镜像重排、街面右半是镜像，仔细看能认出重复；要更好得请美术逐层修像素，或让 Codex 再出几张不同的楼和街面替换镜像部分。
- 小吃亭招牌是抽象字形（提示词禁止可读文字）；如果要真的中文/阿拉伯文招牌，需要放开“无文字”限制。
- 悬浮无人机只是挨打的靶子，没有 AI；巡逻无人机只会巡逻和追人，被标记后没有后果（比如增援、警报）。
- 人物 shader 每个像素最多做约 50 次邻域采样（光晕半径 3），在 4090 上无压力，低端核显没测。
- F9 原色对比只在夜街里有；安全屋和医院要对比，得在编辑器里把材质的 `look` 改成 0。
- 条码疤在 28 像素高的人物上只有 4 × 2 像素，平时主要靠闪红被注意到，要看清靠扫描面板。俯视的 14 个动作因为刀太短找不到手，不显示疤。
- 街上还没有平民 NPC，所以“平民身上的完整条码”暂时只体现在闸门和广告牌上。

# 玩家受击与无人机自爆 v04

在本地无人机 v03 上继续修改，仍以狙击手版本496c188为仓库基线。运行 `Run-Drone.cmd` 可试完整战斗，`Run-Sniper.cmd` 可试此前狙击手。

## 玩家受击保护

实际受到一次敌人伤害后，立即开启0.65秒保护，按60Hz约39个物理帧。前0.3秒是原有受击硬直，随后可移动、跳跃、攻击和闪避，剩余保护以浅蓝闪烁提示。再次命中的攻击返回EVADE，不扣血、不追加击退、不重置硬直，也不延长保护。

保护位于玩家共用 `receive_attack` 入口，近战、狙击弹、机炮弹、步枪弹和自爆共用。它与完美闪避的保护分别计时；完美闪避结束不会清除剩余受击保护。暂停、菜单和对话冻结时，保护和受击动作同步停止。闪避或未命中不会额外开启受击保护。

## 正面与背面受击动画

以命中瞬间的玩家朝向与来袭方向判断正面/背面，受击期间保留朝向。正面受击快速后仰、略微抬起头肩，再回正；背面受击向前屈身、头肩下沉，随后恢复。左右朝向均支持。

动作是基于现有原生像素角色的程序化腰部弯曲动画，包含冲击和回正阶段，未添加手绘逐帧素材。头肩最大偏移正面6像素、背面7像素，脚部固定；人物配色、轮廓光和义体标记跟随变形。真实碰撞体保持12×26，位移仍由物理击退控制。步枪/霰弹枪的零击退不会因为播放受击动画而产生额外位移。

## 低血量自动自爆与效果

无人机默认12生命，生命大于0且降至3或以下（25%）就自动停止射击，进入1.2秒闪红警报，显示64像素危险圈。实际伤害或脚本改变生命都触发同一规则。警报期间再次受击不会重置倒计时，暂停会停止计时。

自爆效果依次表现为短促白热闪光、不规则像素火团、细冲击波、金属碎片和升起消散的烟雾，总视觉时长0.78秒。伤害在引爆时只结算一次，35伤害、击退参数34。撤出范围、实体掩体、及时闪避或现有受击保护均能避免伤害。警报期间补刀击杀仍可中止自爆；从正常血量直接击杀则成为残骸。

## 试玩操作

- AD移动，空格跳跃，鼠标攻击/蓄力，短按Shift闪避。
- H试正面受击，J试背面受击；这两个练习会停住无人机，按R恢复整场战斗。
- B把无人机降到低血量，观察自动自爆；无需按B，正常攻击打到低血量也会触发。
- 1/2/3远距、近距、换侧，C切换掩体，R重开，F1改键，Esc退出。

本轮验证详情见 `docs/verification/combat-v04.json`。本地更新包同时包含此前无人机内容，可覆盖狙击手完整工程或无人机v03；未同步至GitHub。

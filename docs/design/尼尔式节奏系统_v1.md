# 《夜行者》尼尔式节奏系统 v1 设计稿

2026-10-15。用户已定：先不画新帧，用现有长刀帧做节奏系统；只做侧视；第一版包含轻重穿插连段、闪避派生、完美闪避反击、空中旋转斩。双刀帧之后再画，届时只替换“轻击”那一路的动画，招式表和判定逻辑不变。

## 1. 输入

| 输入 | 现在 | v1 |
|---|---|---|
| 左键点击 | 轻击三连 | 轻击（L），连段最多 5 段 |
| 左键按住 | 蓄力重斩 | 不变：挥完这一刀转蓄力，蓄满松开 |
| **右键点击** | 无 | **重击（H），立刻出，不蓄力** |
| Shift | Shift+A/D+左键突刺（正在改成单按） | 单按突刺/闪避，是闪避派生和完美闪避的入口 |
| W+左键 | 上挑 | 不变 |
| 空中 S | 下劈 | 不变 |

需要你定：**重击用右键**。尼尔的轻重是两个键，轻重能在一套连招里快速穿插就靠这一点；长按蓄力太慢，穿插不起来。右键现在空着。

## 2. 地面连段（侧视）

轻击链在原三连后面接两段；任意一段之后按右键，打出对应的终结技（尼尔的“第几段接重击，出不同招式”）。

| 输入 | 招式 | 用哪套帧 | 要点 |
|---|---|---|---|
| L | 一段斩 | attack1 | 原样（36 fps），手感不变 |
| L L | 二段斩 | attack2 | 原样（40 fps） |
| L L L | 三段斩 | attack3 | 原样（42 fps），30% 暴击不变 |
| L L L L | 四段·刺 | stab | 48 fps，前冲 10 px，点刺 |
| L L L L L | 五段·回旋 | attack2 → attack1 连播 | 60 fps，代码画一圈刀光弧，两段判定，收尾稍长 |
| L → H | 突进重劈 | attack3 | 34 fps 慢一拍，前冲 20 px，大判定，击退 |
| L L → H | 挑空斩 | rising_slash | 把敌人挑上天，玩家可跳起接空中连段 |
| L L L → H | 回旋重斩 | attack3 → attack2 | 3 段判定，刀光弧，最后一段算暴击 |
| L L L L → H | 裂地斩 | 小跳 + dive_slash | 落地冲击波，打地面一定范围 |
| H | 单独重击 | attack3 | 34 fps，同“突进重劈” |
| H H | 重击二段 | rising_slash | 挑空 |
| 左键长按 | 蓄力重斩 | attack3 | 现有：蓄满 3 倍伤害、10 帧顿帧（正在加强蓄力动作和 32 px 前冲） |

- 连段窗口沿用现在的“新一次点击才算一段、按住不会自动连”的规则；缓冲 0.22 秒不变。
- 原三连的帧速、顿帧（普通 4 帧、暴击 6 帧）不动，交接说明要求保留。
- 新加的招式用“轻/暴击/重”三档命中特效和音效（已经有了）。

## 3. 闪避派生（dodge offset）

- Shift 突刺之后 0.25 秒内按左键：连段计数**不清零**，接着打下一段；突刺后的第一刀改成“穿影斩”（attack1，52 fps，带残影，判定加长 8 px）。
- 突刺之后 0.25 秒内按右键：“追影重斩”（attack3 加 24 px 前冲）。
- 意思和尼尔一样：闪避不打断节奏，反而是进攻的一部分。

## 4. 完美闪避反击

需要会攻击的敌人和主角的受击状态，现在都没有：

- **敌人**：夜街的悬浮无人机加一个攻击：锁定玩家后眼睛变红闪烁 0.5 秒（预警），然后朝玩家直线突袭（攻击判定 0.12 秒）。木桩不攻击。
- **主角受击（v1 只做反应、不扣血）**：被打中击退约 20 px、红闪、0.3 秒硬直，打断当前招式和蓄力。要不要加血条，你定。
- **判定**：敌人攻击判定生效前 0.2 秒内（或生效期间）按 Shift，且突刺路径确实避开了攻击，就是完美闪避。
- **效果**：慢动作 1.2 秒（实际时间，游戏速度 25%），画面边缘泛青、无敌；这段时间里按左键或右键是“反击”：瞬移到敌人身后斩一刀，伤害 3 倍、10 帧顿帧，之后恢复正常速度。
- **顿帧和慢动作的关系**：顿帧按显示帧和实际时间计，慢动作中命中照样冻结 4/6/10 帧；慢动作计时在顿帧期间暂停，不会被吃掉。具体做法等架构审查结论。

## 5. 空中旋转斩

- 空中三连之后再按左键（或空中按右键）：空中回旋斩，air_attack1 → air_attack2 → air_attack1 以 60 fps 连播，3 段判定，每段都给 0.25 秒滞空，整套下来在空中停约 0.6 秒；配一圈刀光弧。
- 结束接滞空，可以再接 S 下劈。

## 6. 节奏感的公共手段

- 连段越往后，出刀帧速越快（轻击 4、5 段 48–60 fps）。
- 招式之间的取消窗口：命中帧之后即可接下一招，不必等收招播完（只对新招式；原三连不动）。
- 残影：突刺、穿影斩、回旋时留 1–2 个残影。
- 刀光弧：回旋类招式由代码画整圈刀光（像素圆弧，白芯青边），不需要新帧。

## 7. 验证

- 每个招式都进回归：输入序列 → 动画名、命中次数、伤害、顿帧帧数。
- 完美闪避：时间窗口内外各测一次；慢动作里命中，顿帧仍满足 4/6/10 帧；慢动作结束速度恢复。
- 原有 14 组套件保持全过。
- 夜街实机录像（带声音），对比改前改后。

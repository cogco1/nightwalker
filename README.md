## 启动和操作

双击 Run-Demo.cmd 启动；Run-Sandbox.cmd 也打开同一空白场景。Open-Editor.cmd 打开 Godot 工程，Test-Game.cmd 运行当前回归检查。使用已有的 Godot 4.7.2，路径在本机 godot-path.txt 中；更换电脑时按 godot-path.example.txt 设置。

- A / D 移动；侧视空格跳跃，S 蹲下。
- 左键轻击，按住左键蓄力，右键重击；Shift 点按闪避、长按奔跑。
- Tab 在空白侧视和空白俯视之间切换；俯视使用 WASD 移动。
- R 回到空场景起始位置；Esc / F1 打开按键设置。

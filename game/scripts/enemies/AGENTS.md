# 后续怪物的追击约定

用户要求：以后的怪物均复用限定区域追击逻辑，但不默认继承无人机自爆。

- 新敌人接入 `enemy_territory.gd`，以出生点为固定区域中心，提供可调整的区域半径和身体边距。
- 玩家进入区域才能建立追击；离开区域后停止追击并返回，出生锚点不可随追击移动。
- 普通追击、受击位移和特殊突进都要经过区域约束，保留完整碰撞体的边距，不能全图追逐或穿过实体障碍。
- 共用组件只负责区域、目标判断、回归和位移约束。低血量自爆、撤远冲撞自爆属于无人机专属攻击，其他怪物只有在用户明确指定时才添加。
- 新攻击仍通过玩家共用伤害入口处理，兼容受击保护和完美闪避。验证至少包含区域内追击、越界脱离、暂停和实体碰撞。
- 新近战接入 `melee_rhythm.gd`：至少0.55秒完整前摇、0.10秒左右单次有效命中、至少0.55秒收招和0.80秒攻击间隔。标记 `attack_kind: melee`，尊重玩家硬直与近战保护，不能贴身重复刷新伤害或跳过收招。

已单独约定的狙击手保持出生区域内驻守，后续新怪物按本文件接入共用区域逻辑。
